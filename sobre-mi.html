SOBRE MÍ

Favio Vergara

Lima, Perú

Estoy en el 2.º ciclo de Diseño y Desarrollo de Software en Tecsup. Me gusta elaborar sitios web que funcionen correctamente: la interfaz que se vea atractiva y que la base de datos se vea ordenada y limpia.

Aplico mis conocimientos en proyectos prácticos full-stack, abarcando diseño en Figma, frontend con Bootstrap y jQuery, backend con Java POO, Node.js y PHP, y administración de bases de datos en MySQL y Oracle SQL.

Desarrollador de software con experiencia en el desarrollo integral de proyectos. Trabajo la interfaz con tecnologías frontend como HTML5, CSS3, JS, Bootstrap y jQuery, la lógica de negocio en el backend con PHP, Node.js y Java POO, la gestión de datos con MySQL y Oracle SQL, y el control de versiones seguro mediante Git y GitHub.

Transformo diseños de Figma en sitios web institucionales adaptables a cualquier dispositivo. A nivel de backend, desarrollo sistemas transaccionales con inicio de sesión y gestión de datos utilizando Java, Node.js y MySQL.

Gestiono el código fuente en GitHub a través de un flujo colaborativo basado en ramas, revisión de cambios y resolución de conflictos. Complemento este proceso creando documentación técnica detallada para la arquitectura de los proyectos empleando Markdown y diagramas Mermaid.
